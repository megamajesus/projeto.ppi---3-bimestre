## Sobre o Projeto
O sistema é um portal para consulta e gestão de laboratórios e espaços do campus (salas, auditórios, etc.), permitindo verificar localização, capacidade, recursos e disponibilidade.

---

## Tecnologias
- **Backend:** Node.js, Express
- **Visão:** Handlebars
- **Banco de Dados:** SQLite com Sequelize

---

## Como Executar

1. Instale as dependências:
   npm install
   npm start
